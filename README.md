# Hi, I'm Aaryan 👋

This is where the **fun stuff** lives — side projects, experiments, and tools I build because I
wanted them to exist. Work is deliberately kept elsewhere; everything here is evenings-and-weekends
code, shared in case it's useful to you too.

## Things I've built

| | |
|---|---|
| [**AutoLUT**](https://github.com/aaryann123/autolut) | Local colour grader for photos and video — film-stock LUTs, GPU live preview with real-time graded playback, proper HDR → SDR for iPhone footage. Python + FFmpeg + WebGL2. |
| [**Aria**](https://github.com/aaryann123/aria-player) | A FLAC player for macOS and iOS that reads files off your disk, themes itself from the album art, and has a mascot who walks the progress bar. SwiftUI, no dependencies. |
| [**Menu Stats**](https://github.com/aaryann123/menu-stats) | A macOS menu bar system monitor in one Swift file — CPU, GPU, memory, temperature, fans, network, battery — read straight from the kernel and the SMC. One icon in the bar, sparklines in the dropdown. |
| [**Stretch**](https://github.com/aaryann123/stretch) | A macOS menu-bar desk-break timer: one line-drawing stretch every 45 minutes, nothing more. |
| [**Slack Claude Bridge**](https://github.com/aaryann123/slack-claude-bridge) | Run and supervise Claude Code from Slack — start tasks and approve every tool call from your phone. |
| [**Claude Skills Dashboard**](https://github.com/aaryann123/claude-skills-dashboard) | Local web UI to browse, star, copy and edit your Claude Code skills across projects. |

## How I like to build

- **Local first.** No accounts, no telemetry, nothing leaves the machine unless you export it.
- **One good idea per project**, done properly — the colour maths in AutoLUT, the FLAC parser in
  Aria, and the SMC reader in Menu Stats are the parts I'm proudest of.
- **Synthetic demo data** in every repo, so you can try things without handing over your own photos
  or music.

Issues and pull requests are welcome on any of them.
