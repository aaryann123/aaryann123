# Hi, I'm Aaryan 👋

This is where the **fun stuff** lives — side projects, experiments, and tools I build because I
wanted them to exist. Work is deliberately kept elsewhere; everything here is evenings-and-weekends
code, shared in case it's useful to you too.

## Things I've built

| | |
|---|---|
| [**AutoLUT**](https://github.com/aaryann123/autolut) | Local colour grader for photos and video — film-stock LUTs, GPU live preview with real-time graded playback, proper HDR → SDR for iPhone footage. Python + FFmpeg + WebGL2. |
| [**Aria**](https://github.com/aaryann123/aria-player) | A FLAC player for macOS and iOS that reads files off your disk, themes itself from the album art, and has a mascot who walks the progress bar. SwiftUI, no dependencies. |

## How I like to build

- **Local first.** No accounts, no telemetry, nothing leaves the machine unless you export it.
- **One good idea per project**, done properly — the colour maths in AutoLUT and the FLAC parser in
  Aria are the parts I'm proudest of.
- **Synthetic demo data** in every repo, so you can try things without handing over your own photos
  or music.

Issues and pull requests are welcome on any of them.
